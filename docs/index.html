1. ¿Qué es y para qué sirve?

Lumu Defender permite detectar compromisos confirmados, consultar incidentes, indicadores de compromiso y evidencias asociadas.

security.get_compromisesConsulta compromisos/incidentes abiertos.
security.get_iocsConsulta indicadores IOC.
security.get_incidentsObtiene incidentes.
security.get_evidenceConsulta evidencias/contexto.

2. Prerrequisitos

  • Cuenta Lumu Defender.
  • Defender API Key.
  • Permisos de lectura sobre incidentes e IOCs.

3. Configuración en Lumu

  1. Entra a Lumu Defender.
  2. Ve a Settings / API Keys o Defender API.
  3. Genera o copia la API Key.
    [ Captura: API Key en Lumu Defender — reemplazar si aplica ]

4. Permisos requeridos

La API Key debe permitir lectura de incidentes, adversarial activity/IOCs y contexto/evidencias.

5. Configuración en Ruvic

Completa la API Key, base URL opcional, verificación SSL, timeout y límites.

6. Verificación

Ejecuta Probar conexión y consulta incidentes, compromisos, IOCs y evidencias.

7. Solución de problemas

401/403API Key inválida o sin permisos.
404Endpoint o incidente no encontrado.
Sin resultadosAmplía rango de fechas o reduce filtros.

8. FAQ y seguridad

No compartas API Keys. Trata IOCs, incidentes y evidencias como información sensible.
